GloboPersona Frontend

A modern AI-powered frontend application for GloboPersona built with Next.js, React, TypeScript, and Tailwind CSS. This project provides the user interface for creating, managing, and interacting with AI-generated personas and intelligent workflows.

🚀 Features
⚡ Built with Next.js App Router
🎨 Responsive UI with Tailwind CSS
🔐 Authentication support
🤖 AI persona management
📊 Dashboard interface
🌙 Dark/Light mode support
📱 Mobile-friendly design
🔄 API integration with backend services
🧩 Modular component architecture
🛠 Tech Stack
Framework: Next.js
Language: TypeScript
UI Library: React
Styling: Tailwind CSS
State Management: React Hooks / Context API
Package Manager: npm
Deployment: Vercel / Netlify
📂 Project Structure
frontend-globopersona/
│
├── app/                # Next.js app router pages
├── components/         # Reusable UI components
├── public/             # Static assets
├── styles/             # Global styles
├── lib/                # Utility functions
├── hooks/              # Custom React hooks
├── services/           # API service handlers
├── types/              # TypeScript type definitions
├── package.json        # Project metadata & dependencies
└── README.md
⚙️ Installation

Clone the repository:

git clone https://github.com/challarakesh108-glitch/frontend-globopersona.git

Move into the project directory:

cd frontend-globopersona

Install dependencies:

npm install
▶️ Running the Development Server

Start the application locally:

npm run dev

The app will run on:

http://localhost:3000
🏗 Build for Production
npm run build

Start production server:

npm start
🧪 Linting
npm run lint
🔧 Environment Variables

Create a .env.local file in the root directory:

NEXT_PUBLIC_API_URL=http://localhost:8000

Add additional environment variables as required.

📦 Deployment
Vercel

Deploy instantly using Vercel:

vercel
Netlify
npm run build

Upload the generated build folder.
